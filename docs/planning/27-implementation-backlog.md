## 0. How to read this backlog

**IDs.** `Exx-Syy` (epic, story). IDs are stable: never renumber; deprecate with ~~strikethrough~~ and a note. Epic **E28** holds **non-code** business, legal and setup tasks. They are tracked here because several of them sit on the critical path (doc 28 §4).

**Priority.** `P0` = launch blocker (P0 in doc 01, or a P1 committed in doc 02 §1.2, marked `P0*`). `P1` = stretch (doc 02 §1.2 "stretch P1"); build only if the milestone is on schedule. P2 items are not in this backlog (Appendix C).

**Size** (ideal engineer-days, **with Claude Code doing most of the typing**; includes the tests the story's tier requires per doc 20 §2.2, code review and local verification): **S** ≈ 1 d · **M** ≈ 2–3 d · **L** ≈ 4–6 d. Roll-up in Appendix B uses S = 1, M = 2.5, L = 5. Without AI assistance multiply by ≈ 1.6–2. Recalibrate after M0 from measured velocity (doc 28 §3).

**Milestones** (detail and exit criteria in doc 28): **M0** Foundations · **M1** Catalog & discovery · **M2** Ordering + COD end-to-end on local · **M3** Dispatch & delivery golden flow · **M4** Online payments + ledger/settlement · **M5** Admin/ops + notifications hardening (feature complete) · **M6** Cloud staging + production on AWS, security/perf/DR · **M7** Closed pilot · **M8** Public launch in Mahabubnagar. **M0–M5 run entirely on local Docker Compose with fakes; no cloud spend** (baseline §4a, R24).

**Definition of Done.** Every story meets doc 20 §22.1 (spec-first OpenAPI, `x-rovo-permission`, en + te strings, paise end-to-end, migrations up/down, telemetry, redaction, tests tagged `// REQ:` with the IDs listed here). AC below lists only what is specific to the story.

**Rulings override text.** Where doc 01–26 text conflicts with a Lead ruling (R1–R26), stories implement the ruling and cite it, e.g. accept timeout = R1 (180 s → `CANCELLED`/`RESTAURANT_UNRESPONSIVE`), not the `REJECTED`/`RESTAURANT_TIMEOUT` wording still in BR-TIME-002/RES-ORD-004. Open conflicts are listed in doc 30 §5.

**Requirement ranges.** `CUS-AUTH-001..007` means every ID in the range.
